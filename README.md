## 学习内容

### Git 已掌握命令

- `git add` — 将工作区改动暂存到暂存区
- `git commit` — 将暂存区内容提交到本地仓库
- `git clone` — 从远程仓库克隆副本到本地
- `git push` — 将本地提交推送到远程仓库

详细学习过程见 [git学习过程.md](gitstudy.md)。
